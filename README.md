## Функциональность

### Предметная модель
- **Player** — игрок с балансом и методами `make_bet`, `receive_cash`, `go_bankrupt`.
- **Goose** — базовый гусь: крик (`honk`), попытка кражи (`steal`), магический метод `__call__`.
- **WarGoose** — наследник, который атакует игроков (усиленная кража).
- **HonkGoose** — наследник с уникальным “криком” и эффектами на баланс игрока.
- **Chip** — фишки казино со стандартными цветами и номиналами (словарь `STANDARD_CHIPS`).  
  - Важно: **складывать (через `+`) можно только фишки одного цвета**.  
    Если попытаться сложить фишки разных цветов, будет выброшен `ValueError`.  

### Пользовательские коллекции
- **CasinoBalance** — словарная коллекция (ключ: имя игрока, значение: объект Player).
  - Поддерживает операции по имени игрока и логирует изменения баланса в консоль.
- **PlayerCollection** — списковая коллекция (композиция над CasinoBalance).
  - Поддерживает индексацию, срезы, итерацию, добавление и удаление игроков.

### Псевдослучайная симуляция
- `Casino.run_simulation(steps=20, seed=None)` запускает симуляцию на заданное число шагов.
- При указании `seed` последовательность событий будет воспроизводимой.
- На каждом шаге происходит ровно одно случайное событие, и каждое событие логируется в консоль.

## Установка и запуск

### Требования
- Python 3.12+
- pytest для запуска тестов

### Запуск программы

Из корневой директории проекта:

```
python -m src.main
```

## Запуск тестов

```
pytest tests/ -v
# или
python -m pytest tests/ -v
```

## Использование

После запуска программа выводит меню и инструкцию, затем просит ввести параметры симуляции:

- `steps` — количество шагов (по умолчанию 20)
- `seed` — необязательный seed для воспроизводимости (можно оставить пустым)

Пример:

```
ГЛАВНОЕ МЕНЮ
Казино и гуси: симуляция
Введите количество шагов (steps) и необязательный seed.
Если seed задан, последовательность событий будет воспроизводимой.

steps (по умолчанию 20): 10
seed (пусто = случайно): 42
```
